This project demonstrates a "modern Ticket Management Web Application** implemented in two frontend frameworks":
 React.js (Vite)
 Vue.js (Vite)

Each version provides identical functionality and a consistent UI — built to test cross-framework architecture design, routing, state management, and UI consistency.



 Overview

Framework | Folder | Description |

React | `ticket-management-react/` | Built using React 18 + Vite |
Vue.js | `ticket-management-vue/` | Built using Vue 3 + Vite |

Both share:
- Authentication flow (Login / Register)
- Dashboard with ticket overview
- Full CRUD (Create, Read, Update, Delete) ticket management
- Reusable, responsive design
- GitHub Pages-ready configuration



 Core Features

 Landing Page with hero section and CTA buttons  
 Login and Signup forms with validation  
 Dashboard displaying ticket summaries  
 CRUD operations for managing tickets  
 Clean UI with responsive design  
 Modular routing structure  
 Simple state handling (local or reactive)  
 Fast development with Vite  



Tech Stack

Category | React Implementation | Vue Implementation |

Framework | React.js 18 | Vue.js 3 |
Router | React Router DOM | Vue Router |
State | useState / useEffect | Composition / Options API |
Build Tool | Vite | Vite |
Styling | CSS / Tailwind (optional) | CSS / Tailwind (optional) |



Setup Instructions

React Version


Clone the repo
git clone https://github.com/<your-username>/ticket-management-react.git

Navigate to project
cd ticket-management-react

Install dependencies
npm install

Run development server
npm run dev
